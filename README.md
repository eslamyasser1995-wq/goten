# goten goten – دليل التشغيل (من الموبايل فقط)

النظام فيه 3 صفحات:

| الصفحة | لمين | الرابط بعد الرفع |
|---|---|---|
| `index.html` | العملاء (التسوق، السلة، الطلب، التتبع) | `https://USERNAME.github.io/islamko/` |
| `driver.html` | المناديب (الطلبات المعيّنة، اتصال، خريطة، تم التوصيل) | `.../driver.html` |
| `admin.html` | أنت (منتجات، أسعار، صور، أقسام، بنرات، طلبات، مناديب، إعدادات) | `.../admin.html` |

---

## المرحلة 1: جرّبه فوراً (وضع تجريبي)
بدون أي إعداد، النظام يشتغل في **وضع تجريبي**: البيانات تتحفظ على نفس الجهاز فقط.
- لوحة التحكم: PIN = `1234`
- تقدر تضيف منتجات وترفع صور وتغيّر أسعار وتشوف التغيير فوراً في صفحة العملاء على نفس الموبايل.

> ⚠️ في الوضع التجريبي، طلبات العميل على موبايله ما توصلك على موبايلك. للتشغيل الحقيقي لازم المرحلة 2.

## المرحلة 2: الرفع على GitHub Pages (مجاني)
1. ادخل github.com من Safari وسجّل دخول.
2. **+ › New repository** › الاسم `islamko` › Public › Create.
3. **Add file › Upload files** › ارفع كل الملفات (بما فيها مجلد `icons`). لو Safari ما رفع المجلد، أنشئ ملف باسم `icons/icon-180.png` وارفع الأيقونات فيه.
4. **Settings › Pages** › Source: `Deploy from a branch` › Branch: `main` / `root` › Save.
5. بعد دقيقة الرابط يشتغل: `https://USERNAME.github.io/islamko/`

## المرحلة 3: قاعدة البيانات الحقيقية Supabase (مجاني)
1. ادخل supabase.com › Start your project › سجّل بحساب GitHub.
2. **New project** › اسم `islamko` › كلمة سر قوية › Region: أقرب منطقة (مثلاً Frankfurt أو Mumbai).
3. **SQL Editor › New query** › الصق محتوى ملف `supabase.sql` كامل › **Run**.
4. **Authentication › Sign In / Providers › Email**: اقفل خيار **Confirm email** (عشان الحسابات تشتغل فوراً) – أو خليه وأكّد الإيميل من بريدك.
5. **Project Settings › API**: انسخ `Project URL` و `anon public key`.
6. في GitHub افتح `config.js` › ✏️ Edit › حط القيمتين:
   ```js
   SUPABASE_URL: "https://xxxx.supabase.co",
   SUPABASE_ANON_KEY: "eyJhbGciOi...",
   ```
   › Commit changes.
7. افتح `admin.html` › اكتب إيميلك وكلمة سر › **إنشاء حساب أدمن جديد**.
8. ارجع Supabase › SQL Editor › شغّل (غيّر الإيميل):
   ```sql
   update public.profiles set role = 'admin'
   where id = (select id from auth.users where email = 'you@example.com');
   ```
9. ادخل `admin.html` › ابدأ أضف الأقسام والمنتجات والصور والبنرات.

> مفتاح `anon` مسموح يكون ظاهر في الصفحة؛ الحماية الحقيقية في قواعد الصلاحيات اللي في `supabase.sql`: العميل ما يقدر يغيّر سعر، والمندوب يشوف طلباته بس، والأدمن بس يعدّل المنتجات ويرفع الصور.

## المناديب
1. المندوب يفتح `driver.html` › «مندوب جديد؟ سجّل هنا» › يكتب اسمه ورقمه وإيميل وكلمة سر.
2. أنت من `admin.html` › تبويب **المناديب** › غيّر صلاحيته إلى **مندوب**.
3. في **الطلبات** اختار المندوب للطلب › يظهر عنده فوراً (تحديث كل 15 ثانية).

## تثبيته كتطبيق على الآيفون
افتح الرابط في **Safari** › زر المشاركة ⬆️ › **إضافة إلى الشاشة الرئيسية**. يظهر بأيقونة إسلامكو ويفتح ملء الشاشة.
اعمل نفس الشيء لـ `admin.html` على موبايلك، والمناديب لـ `driver.html` على موبايلاتهم.

## ملاحظات مهمة
- **الدفع**: حالياً «كاش» و«كي نت عند الاستلام» (جهاز المندوب). الدفع أونلاين بكي نت يحتاج حساب تاجر عند بوابة دفع كويتية (MyFatoorah / Tap / UPayments) – نضيفه لما يكون عندك الحساب.
- **App Store**: نشره كتطبيق رسمي في متجر آبل يحتاج حساب Apple Developer (99$ سنوياً) وجهاز Mac أو خدمة بناء سحابية. نفس الكود ينفع يتغلّف بـ Capacitor وقتها.
- **الإشعارات**: الأدمن يسمع تنبيه صوتي لما يجي طلب جديد والصفحة مفتوحة.
- الأسعار بالدينار الكويتي بثلاث خانات (فلس).
